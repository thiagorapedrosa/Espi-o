# Disfarce

Jogo do impostor para jogar em família, offline e sem assinatura.
Todo mundo vê a mesma figura secreta, menos o impostor.

**Baixar o APK:** abra a página **Releases** deste repositório e baixe o `Disfarce.apk` da versão mais recente.

Como compilar e personalizar: veja o [LEIA-ME](LEIA-ME.md).
